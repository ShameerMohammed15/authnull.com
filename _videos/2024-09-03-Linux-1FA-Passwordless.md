This showcases Linux Authentication  1FA Passwordless authentication (interactive). This demo uses active directory based passwordless credentials to log on.

This solution is a modern approach to machine to machine authentication without having to worry about shared secrets, passwords, SSH keys, credential rotation and many more problems that arise with large distributed infrastructure in enterprises.
