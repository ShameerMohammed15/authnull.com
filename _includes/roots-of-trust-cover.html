Security Approach

Two roots of trust

AuthNull is a decentralized, vaultless system with two roots of trust (two pairs of public / private keys) - that are requried to issue and sign credentials before infrastructure is accessed.

How does this work?

Admins are issued public / private key pairs and they reside on admin wallet. Additionally claims are logged on public blockchains.

When users are issued credentials, admin claims are used to issue the same. Users are issued their own private keys (which resides in their wallets).

All user claims ust be signed by the users' private keys in order to be able to access any infrastructure.

Security Approach

Identity linked authentication

AuthNull delivers an identity linked authentication using biometrics, a verifiable identity linked to the organization's account to deliver prvileged access.

How does this work?

Every user is issued public/private key pairs after their organization identity is verified.

User's private keys are tied to biometrics. All authentication is forced through biometrics

What this means is that even if the user shares passwords to a machine, no one else can login unless users' identity is verified using biometrics.

Security Approach

Restoration of Wallet with Seed Phrases

What do you do when you lose access to the Wallet on your mobile phone?

AuthNull uses BIP39 [Bitcoin Improvement Proposal number 39 (BIP39)] to generate seed phrases which can be used to restore the wallet in case the device was lost.

While this has nothing to do with Bitcoin itself, it was pioneered within the blockchain commuity to restore access to the users' decentralized wallets.

How does this work?
AuthNull generates a set of seed phrases which needs to be noted down. When attempting to restore, these seed phrases can be used to acquire a new public-private keypair for the user.
