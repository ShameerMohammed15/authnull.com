Endpoint Security

Comprehensive and Simplified Endpoint security

AuthNull provides comprehensive endpoint security needs

Logging

AuthNull enables extensive logging - agent, APIs, and all other interaction points within the system. These logs can be shipped to any SIEM of your choice or to an ELK dashboard provided by AuthNull

Runtime guardrails and protection

AuthNull comes built in with Runtime guardrails with compliance checks - MITRE, NIST, CIS, IS0 27001, PCI-DSS, SOC2 Type 2 and more.

Cryptography

AuthNull supports cryptographic encryption of credentials in compliance with FIPS 186-5 Digital Signature Standard (DSS)

Tamper evident credentials

AuthNull provides tamper evident credentials with the use of credential hashes, as well as hashes of transaction histories enabling us to verify transactions.
