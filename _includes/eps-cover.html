Deploy Endpoint security

AuthNull delivers powerful endpoint security for windows with extensive features including whitelisting, blacklisting, removal of admin privileges and more.



Key Features

AuthNull's endpoint security for Windows provides comprehensive features including:

Remove Admin Privileges

Automatically remove privileges for given endpoints without users even noticing it.

Application whitelisting and blacklisting

Whitelist or blacklist applications using wildcards, application names, paths, publisher names or md5 hashes.

Policies and rules

Create policies and rules targeting single endpoints or a range of endpoints.

Monitor UAC

Monitor user access control events and approve them on adhoc basis, or automatically with the help of rules.

MFA Biometric Authentication

Deliver highly secure MFA authentication that includes biometrics which ensures that endpoints are not compromised even if credentials are shared.

Audit logs

AuthNull generates audit logs to meet compiance needs. These logs can be integrated with any SIEM solution.

Use cases

AuthNull's Endpoint privileged security can be used for the following use cases:

01

Shared domain admin credentials

For critical endpoints, you can use AuthNull to share domain admin credentials based on rules, or based on checkouts to users.

02

Automated user onboarding / offboarding

Thanks to a centralized endpoint privilege management - end users are onboard and offboarded. This means no need to change passwords, SSH Keys manually.

03

Passwords and SSH Key rotations & automated distributions

Where setup, passwords and SSH Keys are automatically rotated and distributed to users wallets.

04

SSO with MFA

Enable login to endpoints using a single sign on with MFA, or direct to endpoints with MFA

05

Isolate and protect domain admin accounts

Domain admin accounts cannot be accessed without a SSO, multifactor and a one time password or token that is temporary in nature.
