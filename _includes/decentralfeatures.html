Solutions

AuthNull provides standards based passwordless solution for legacy infrastructure access.

Passwordless access to Linux Infrastructure

Authnull provides passwordless privileged access management for access and authentication to Linux infrastructure that use existing authentication mechanisms such as Active Directory.

Passwordless for web apps

Authnull provides passwordless for Webapps using Fido2 / WebAuthN standards.

Passwordless PAM

Authnull provides PAM (user management, endpoint management, privilege escalation etc) for Linux devices with the added advantage of passwordless authentication.

Decentralized identity

Authnull’s primary method of authentication is a decentralized id. Issued to a wallet with verified user credentials.
