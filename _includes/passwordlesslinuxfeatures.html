Passwordless Features

Support for SSH, Local (Posix) and LDAP authentication

AuthNull can enable local, or centrally managed authentication such as Active Directory with Passwordless credentials.

Enable 1FA or 2FA with backward compatbility support for SSH Keys / Passwords

AuthNull can completely eliminate passwords and SSH Keys. However should you require for backward compatibility you can add a 2FA credential that is available through a user's authentication wallet.

Decentralized Credentials

Authnull provides decentralized credentials with W3C verified credentials format.

Your Authenticator Wallet is your Vault

The Decentralized Verified Credentials enables every user to maintain their vault of credentials on the Authenticator Wallet App. The credentials are protected by Biometric and signed using private keys owned by the user on the wallet.
