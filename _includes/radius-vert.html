Authentication Flow

Once AD validation is successful, NPS forwards the request to FreeRADIUS:
- Communication is encrypted using shared secrets
- Uses UDP ports 1812 (authentication) and 1813 (accounting)
- Includes relevant RADIUS attributes

// 02

Final Authorization

The system completes the authentication chain:
- AuthNull returns MFA results
- FreeRADIUS makes final access decision
- NPS enforces the decision
- User receives access grant or denial
