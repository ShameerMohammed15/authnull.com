Platform Approach

Our platform provides lightweight, accelerated rollout of passwordless PAM on your infrastructure infrastructure.

Frictlionless & Passwordless Authentication

AuthNull enables frictionless, and passwordless authentication at scale.

Security: Two roots of trust

A distributed set of credentials together with the organization's private keys enable two roots of trust as opposed to a singular entity such as a root CA.

Vaultless approach with a Decentralized Wallet

AuthNull eliminates the need for a vault, using Decentralized credentials that are directly sent to a user's mobile authenticator wallet. AuthNull provides a wallet that is used as a credential store as well as an authenticator.

Login to local (Posix/Windows) or Active Directory /LDAP user accounts

AuthNull enables login to local or centrally managed user accounts. Additionally users can use SSH, RDP, Telnet and other protocols for remote logins.
