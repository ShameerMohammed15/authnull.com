What differentiates AuthNull?

AuthNull delivers Privileged Access Management (PAM) using Decentralized Identity eliminating the need for a centralized vault and by improving security.

Passwordless Authentication

AuthNull enables frictionless, and passwordless authentication to your Linux and Windows endpoints.

More secure with two roots of trust

AuthNull uses two roots of trust (wallet holder, organization) with two public/private key pairs for every authentication making it far more better than using a single root CA.

Manage Passwords,SSH Keys and Secrets without a Vault.

AuthNull removes the need for a vault, using Decentralized wallet app. A wallet that is used as a credential store as well as an authenticator holds all credentials for each user in a decentralized manner.

Local, or LDAP accounts on Server Endpoints.

AuthNull enables login to local or centrally managed user accounts. Additionally users can use SSH, RDP, Telnet and other protocols for remote logins.
