Updates to the platform for June 2023

<br/><br/>
<h3 class="text-2xl ">Wallet App</h3>
The wallet app is now updated to be available on both iOS and Android and includes 

--- Credential details screen for passwordless verified credentials (VC) and other types of credentials  
--- SSH keys as verified credentials <br/>
--- Passwords as verified credentials  <br/>
--- Improved credentials listing   <br/>
--- Improved authentication experience  <br/>
--- Ability to access Passwords and SSH Keys through the wallet <br/>

<br/>


<h3 class="text-2xl ">OKTA SSO, Roles, RBAC and AuthN and AuthZ</h3>
Support for OKTA SSO with SAML2
--- Login with your organization's OKTA SSO tenant
--- RBAC support with multiple roles<br/>
--- End user section for end user role now available<br/>
--- Admin section accessible via admin role   <br/>
--- 1FA or 2FA login for web UI  <br/>
--- Authentication and Authorization now standard across all platform APIs and instances<br/>
