Updates to the platform for June 2023

<br/><br/>
<h3 class="text-2xl ">Privileged Access Management</h3>
 - new version of jump server that automatically collects credentials relating to VNC, SSH, RDP and passwords from credential wallet
 - upgraded support for RDP, VNC, Telnet and SSH
 - Session recording for RDP, and SSH sessions updated to be significantly faster
 - Minor encoding issue which introduced special characters in text recording has been fixed.
 - Auto install jump server on existing endpoints
 - Auto populate jump server information while creating a connection.
<br/>


<h3 class="text-2xl ">New: Credential Rotation Policy screens</h3>
New Credential Rotation policy screens for SSH Keys and Passwords
--- Set credential rotation policies
--- Automatically distribute SSH Keys and Passwords to those users who have checked out the local user accounts<br/>
--- Credential rotation audit log now stored as a part of agent audit log<br/>
