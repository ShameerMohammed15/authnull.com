<br/><br/>
<h3 class="text-2xl ">Privileged Access Management</h3><br/>
--  Jump server upgrades: Updated jump server that automatically collects credentials relating to VNC, SSH, RDP and passwords from credential wallet. No more manual authentication when logging into connections. No more manual password sharing.
 <br/><br/>
-- RDP / VNC / Telnet: upgraded support for RDP, VNC, Telnet and SSH
 <br/><br/>
-- Session Recording for RDP -  Session recording for RDP now available.
 <br/><br/>
-- Jump Server Installation and connection configuration: Auto install jump server on existing endpoints. Auto populate jump server information while creating a connection.
 <br/><br/>
-- Bug fixes: Minor encoding issue which introduced special characters in text recording has been fixed.

<br/>


<h3 class="text-2xl ">New: Credential Rotation Policy screens</h3><br/>
-- New Credential Rotation policy screens for SSH Keys and Passwords that allows setting up of one or more rotation policies for your endpoints. <br/><br/>
-- Automated distribution: Automatically distribute SSH Keys and Passwords to those users who have checked out the local user accounts
